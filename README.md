# GiveMeOC —— 秋招信息站（offerbiu 缓存版）

展示秋招/春招信息的前端站点。部署于阿里云 ESA Pages（静态资源 + 边缘函数），由边缘函数把 offerbiu 招聘 API 全量缓存进边缘 KV，用户访问时只在缓存过期时**顺手做一次增量同步**（Stale-While-Revalidate），平时读缓存零上游请求。

站点带 **TOTP 访问门禁**：未登录只能看到登录页，数据接口一律 401。

## 首次部署

1. **生成访问密钥**（TOTP = 验证器 App 里的 6 位动态口令）：
   ```bash
   node scripts/setup-totp.mjs
   ```
   用 Google / 微软 / 1Password 等验证器扫码（或手输 Base32 密钥），按提示输入一次 6 位数字完成校验。
2. **配置函数变量**：ESA 控制台 → 边缘计算和 AI → 函数和Pages → 目标函数 → 基本信息 → 函数变量
   → 添加变量：键 `TOTP_SECRET`，值 = 上一步生成的密钥，**建议勾选「加密存储」**。
   ⚠️ 变量需**重新部署版本**后才生效；未配置时站点拒绝一切访问（页面与 API 一律 500）。
3. 前端构建 `npm run build`（产物 `dist/`），按既有流程发布（入口 `edge-function/api-proxy.js`）。
4. 控制台创建边缘存储空间 `oc`（已建可跳过）。
5. **预热全量数据**（只跑一次，期间站点照常可用）：
   ```bash
   node scripts/prewarm.mjs https://你的域名 2027
   ```
   自动分批抓取并 `final` 聚合；中断后重跑同一命令即可续传。
6. 验证：访问站点应出现登录页，输入验证器上的 6 位口令进入。
   `GET /api/sync?season=2027&key=<SYNC_KEY>&status=1` 返回 `ready=1` 即预热完成。

## 访问鉴权（TOTP 门禁）

门禁开在**边缘函数**而非前端——前端拦截可被 devtools 绕过，服务端拦截不行。

| 情况 | 结果 |
| --- | --- |
| 未登录访问页面 | 边缘函数直接返回登录页（200，内联 HTML） |
| 未登录访问 `/api/*` | `401 unauthorized` |
| 登录 | `POST /api/login`（表单或 JSON，字段 `code`）→ 下发 `oc_auth` Cookie（HttpOnly + Secure，30 天） |
| 登出 | `/api/logout` |

- 会话凭据由密钥派生（HMAC-SHA1），Cookie 中不含明文口令。
- 同一动态口令 90 秒内只能成功一次（防重放）；容忍 ±1 个时间窗（±30 秒）抵消时钟漂移。
- **静态资源（js/css/图标）未登录也放行**，登录页不依赖外部资源，其中不含任何数据。
- **`/api/sync` 不依赖会话，靠 `SYNC_KEY` 独立鉴权**，便于命令行预热与重建。
- 手机时间不准会导致校验失败，请确保验证器设备开启网络时间同步。

## 运维与回归

- 强制刷新：`/api/sync?season=2027&key=...&mode=refresh`；查看状态：`&status=1`
- 全量重建：重跑 `scripts/prewarm.mjs` 即可，无需清库
- 改动 `edge-function/api-proxy.js` 后跑本地回归（内存 KV + 模拟数据源，覆盖缓存、增量、鉴权共 42 项断言）：
  ```bash
  node scripts/worker-sim.mjs
  ```

## 已知边界

- **删除滞后**：数据源侧删除的记录不会被懒增量发现（只见得到顶到列表前的新导入），需清理时手动全量重建。
- **搜索语义近似**：离线 `q` 匹配公司名/岗位文本子串，与服务端语义可能略有出入。
- **筛选选项缓存 6 小时**：下拉项可能滞后，不影响列表数据（懒增量不过滤类型）。
